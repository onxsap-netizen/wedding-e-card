# Wedding Invite

A single-file wedding invitation. Everything is inside `index.html`, including the photos and the opening logo.

## Put it online with GitHub Pages

1. Create a new **public** repository on GitHub.
2. Upload `index.html` (and this README) to the root of the repository.
3. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", pick **main** and **/ (root)**, then save.
4. After a minute your invite is live at `https://<your-username>.github.io/<repo-name>/`.

## Change names, logo, date, venue and RSVP

1. Open your invite link with `#edit` at the end, for example
   `https://<your-username>.github.io/<repo-name>/#edit`
2. Edit anything in the dashboard. The page updates as you type.
3. Press **Download updated index.html**.
4. In your GitHub repository, upload the downloaded `index.html` so it replaces the old one, and commit.
   The live invite updates within a minute or two.

Guests never see the edit button. It only appears when the link ends in `#edit`.

## RSVP

Guests' replies open WhatsApp with a ready-made message to the number you set under **RSVP** in the dashboard.
Use the full number with country code and no `+` or spaces, for example `919876543210`.
